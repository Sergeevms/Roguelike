# Roguelike

Roguelike - simple 2D game project being developed as part of educational course.

## License
[MIT License](LICENSE.md)

## Short description
The player moves through a randomly generated labyrinth, killing enemies and collecting loot. 

## Technologies
The project uses C++ 20 standard with [SFML library](https://github.com/SFML/SFML). The base architecture follows the entity-component system pattern.

## Controls
- __WASD/arrows__ : Movement
- __Spacebar__ : Attack
- __Left Shift__ : Block
- __T__ : Level transfer (successful if level complete conditions met)
- __F11__ : Turn on/off debug render
- __F10__ : Turn on/off input logging
