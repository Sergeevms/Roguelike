# Roguelike

Roguelike - simple 2D game project being developed as part of educational course.

## License
MIT License

## Short description
The player moves through a randomly generated labyrinth, killing enemies and collecting loot. 

## Controls
- WASD/arrows : Movement
- Spacebar : Attack
- Left Shift : Block
- T : Level transfer (successful if level complete conditions met)
- F11 : Turn on/off debug render
- F10 : Turn on/off input logging
